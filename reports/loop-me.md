# loop-me - 详细分析报告

## 📌 基本信息
- 分类：in-progress
- 技能定位：通过“灵魂拷问”帮你把日常重复性工作梳理成可自动化的工作流说明书。
- 适用人群：想要用AI自动化日常工作，但不知道从何下手、需求模糊的职场人或开发者。
- 使用难度：⭐⭐（需要配合AI工具使用，但对话过程像聊天一样自然）

## 🎯 它是干什么的
你平时总有一些重复性的工作（比如每天早上整理邮件、每周五写周报）。你想让AI帮你自动干这些活，但AI不知道具体该怎么干，你自己也说不清细节。`loop-me` 就像一个极其严谨的“产品经理”，它会反过来对你进行“灵魂拷问”，一次只问一个关键问题，还附带建议答案。通过这种一问一答，它帮你把模糊的想法变成一份极其详细、连AI都能直接照着干活的“工作流说明书”，彻底解决AI干活时“自由发挥”导致的翻车问题。

## 🚀 使用场景
1. **日常行政自动化**：你想自动化“每天早上收集各部门数据并生成汇总邮件”的流程，但不知道需要哪些步骤，用它来梳理。
2. **内容创作工作流**：你想建立一个“每周将一篇长文拆解成5条社交媒体短文”的流程，用它来定义触发条件和人工审核节点。
3. **客户支持处理**：想自动化“初步回复客户常见问题并分类”的流程，用它来确定AI能自己处理到什么程度，什么时候必须转交人工。
4. **个人习惯管理**：想自动化“每周日晚上规划下周日程”的流程，用它来设计提醒机制和输入输出格式。

## 🔄 核心工作流程
1. **发现“循环”（Loop）**：AI首先帮你识别生活或工作中那些重复发生、有规律可循的活动（比如“每周一早晨”、“每次收到特定邮件”），把生活看作一个个循环。
2. **灵魂拷问（Grilling）**：AI开始提问。它遵循“一次一问”原则，绝不一次性甩给你一堆问题。每个问题都会附带AI的“建议答案”，你只需要做选择题或判断题，而不是做填空题。
3. **推迟人工干预（Push right）**：AI会尽量让流程自动化，把需要人做决定的环节（检查点）尽量往后推。并且要求AI提供极简的“决策简报”，让你一眼就能做决定，而不是看一堆原始数据。
4. **生成说明书（Spec）**：当所有细节都确认完毕，AI会生成一份标准的工作流说明书。这份说明书详细到另一个AI拿到它就能直接干活，不需要再问任何人。

## 🧪 实测/模拟记录
**模拟场景**：我想让AI帮我自动处理“每天整理技术社区新闻并推送给团队”的工作。

- **我**：我想弄一个工作流，每天把技术社区的好文章整理发给团队。
- **loop-me**：好的，我们来设计这个“每日新闻推送”循环。第一个问题：这个工作流是由“每天早上8点定时触发”，还是由“当社区出现新文章时事件触发”？我建议用定时触发，因为团队习惯在早会时集中看新闻。你觉得呢？
- **我**：定时触发吧，每天早上8点。
- **loop-me**：明白。第二个问题：AI 筛选文章的标准是什么？我建议设定为“只筛选得分超过50且包含‘AI’或‘编程’标签的文章”。你同意这个筛选条件吗？
- **我**：同意，但还要加上“排除招聘贴”。
- **loop-me**：已记录。第三个问题：推送给团队的形式是什么？我建议AI生成一份包含“文章标题、一句话摘要和链接”的简报，直接发到工作群的新闻频道。你需要人工审核后再发，还是直接自动发？我建议先自动发，如果效果不好再加人工审核，尽量让AI多干活。
- **我**：直接自动发吧，我相信它。
- **loop-me**：好的，所有关键决策已确认。正在生成工作流说明书... [生成 workflows/daily-tech-news.md]。说明书已完成，任何执行者AI现在都可以直接照做，无需再问问题。

## ✅ 优点
1. **极度降低认知负担**：一次只问一个问题，且提供建议答案，把“做填空题”变成了“做选择题”，用户不会感到烦躁或无从下手。
2. **强制理清需求**：通过严密的逻辑追问，把模糊的“我想自动化”变成了精确的“触发条件、处理逻辑、输出格式”，杜绝了AI干活时“自由发挥”导致的翻车。
3. **推崇“最少人工干预”理念**：其“向右推”和“简报”的设计哲学非常先进，真正发挥了AI的自动化价值，而不是让AI变成需要人类不断微操的半成品。

## ⚠️ 局限性与注意事项
1. **处于测试阶段（in-progress）**：作为 beta 技能，其规则和输出格式可能会在未来发生变化，且没有集成到官方主流插件包中，需要单独手动安装。
2. **依赖用户的业务判断力**：虽然AI会引导，但如果用户本身对自己的业务逻辑一窍不通，或者无法准确判断AI提供的“建议答案”是否合理，梳理过程可能会卡壳或产出错误的说明书。

## 👥 适合谁用 / 不适合谁用
- **适合谁用**：每天被重复性琐事缠身，想要用AI提效但不知道如何拆解任务的职场人、项目经理、独立开发者；喜欢结构化工作方式的“细节控”。
- **不适合谁用**：只是偶尔想写个简单脚本，不想做复杂规划的人；业务逻辑本身极其混乱、连自己都说不清规则，指望AI能“无中生有”变出完美流程的人。

## 📊 综合评分

- 创新性：9/10（将“拷问”机制和“向右推”哲学完美结合，是提示词工程的高级应用）
