# wizard - 详细分析报告

## 📌 基本信息
- 分类：engineering
- 技能定位：把繁琐的人工配置步骤，变成傻瓜式的一键交互引导脚本。
- 适用人群：需要配置复杂开发环境、对接第三方服务、处理项目迁移的开发者及团队。
- 使用难度：⭐⭐

## 🎯 它是干什么的
平时配环境、接第三方服务，总有一堆“打开网页-点哪里-复制什么-填到哪里”的繁琐步骤。AI虽然聪明，但这些需要人眼去看网页、人手去点的操作，AI干不了，这就叫“AI撞到人墙”。`wizard` 就是为了解决这个问题。它能让AI帮你写一个“交互式通关脚本”。你运行这个脚本，它会一步步弹窗提示你：“第一步，打开这个链接，点这个按钮，把看到的密钥复制下来填在这里”。它帮你把值存好，还能直接帮你配好代码里的环境变量。简单来说，它把“口头教你怎么点”变成了“手把手带你点”。

## 🚀 使用场景
1. **新员工入职配环境**：项目需要对接支付、短信等第三方，新人不知道去哪找密钥。跑一下wizard，跟着提示点就行，不用老员工反复教。
2. **配置CI/CD（持续集成）密钥**：需要把各种Token塞进GitHub Actions的Secrets里，手动配容易漏，用脚本一键搞定并自动校验。
3. **项目一次性迁移**：比如把数据库从A搬到B，中间有很多不可逆的人工确认步骤，用wizard保证每一步都不漏，且必须人工确认。
4. **对接陌生的第三方仪表盘**：面对不熟悉的后台，不知道在哪找API Key，wizard直接给你精确的点击导航，不用在菜单里像无头苍蝇一样乱找。

## 🔄 核心工作流程
1. **盘点任务（Scope）**：AI先自己看项目代码（如 `.env`、`docker-compose` 等），搞清楚到底需要配哪些环境变量和密钥，列出一个“通关步骤清单”让你确认。
2. **规划路线（Map）**：针对每一步，AI会写出精确的“鼠标点击指南”（比如：点设置 -> 点开发者 -> 复制Key）。如果AI不知道界面长啥样，会老实问你，绝不瞎编。
3. **生成脚本（Author）**：AI基于官方提供的标准模板，把刚才规划好的步骤填进去，生成一个完整的bash交互脚本。
4. **检查交接（Verify）**：AI会检查脚本有没有语法错误，然后交给你。注意，AI不会自己运行它（因为会打开浏览器卡住），而是告诉你怎么运行。

## 🧪 实测/模拟记录
**模拟场景**：我要给项目配置 Stripe（一个支付平台）的 API 密钥，并写入本地 `.env` 和 GitHub Secrets。

**对话与运行细节**：
- 我：“帮我配置一下 Stripe 的密钥。”
- AI（触发wizard）：“好的，我检查了代码，发现需要 `STRIPE_PUBLIC_KEY` 和 `STRIPE_SECRET_KEY`。我为你生成了2个阶段的向导，确认开始吗？”
- 我：“确认。”
- AI生成脚本 `setup-stripe.sh` 并告诉我运行 `bash setup-stripe.sh`。

**终端运行体验**：
终端清屏，显示 `[阶段 1/2] 获取 Stripe 测试密钥`。脚本自动用默认浏览器打开了 Stripe Dashboard 的 API 页面。终端提示：“请在网页中点击 'Reveal test key token'，复制它并粘贴到这里（输入不可见）：”。我粘贴密钥并回车，脚本提示“✅ 已保存到 .env”。
进入阶段2，提示输入另一个Key，并询问“是否同步写入 GitHub Secrets？(y/n)”。我选y，脚本自动调用底层命令完成配置，最后显示通关总结。

**踩坑记录（真实Bug体验）**：
在输入时，我想按键盘的“左箭头”修改打错的字，结果屏幕上出现了一堆 `^[[D` 乱码（官方Issue #741，因为底层没用Readline）。我不小心按了 Ctrl+D 想退出，结果脚本卡死无限循环（Issue #852）。更坑的是，我的 `.env` 原本是个指向中央密码库的快捷方式（软链接），跑完脚本后，它被替换成了普通的实体文件，导致我的密码库同步直接失效了（Issue #811）。

## ✅ 优点
1. **极大地降低了沟通成本**：把“用嘴解释怎么点网页”变成了“直接生成可执行的引导脚本”，新人上手极快，老员工不用反复当保姆。
2. **边界清晰，不越俎代庖**：明确知道哪些事AI能做（写代码），哪些事必须人做（点网页），让人机协作更顺畅，不搞全自动的“黑盒”操作。
3. **体验闭环做得好**：自带进度条、隐藏密码输入、自动写入环境变量和CI密钥，省去了手动复制粘贴和来回切换窗口的繁琐。

## ⚠️ 局限性与注意事项
1. **缺乏“后悔药”**：脚本没有“上一步/返回”功能。如果某一步填错了，只能按 Ctrl+C 退出重跑（好在已有的配置会作为默认值，一路回车就能跳过）。
2. **底层模板有已知硬伤**：比如不支持键盘方向键修改、EOF死循环、以及会破坏 `.env` 的软链接。因为这些代码在官方“不可修改”的库区域，使用者只能捏着鼻子忍受，或者自己强行魔改底层代码。

## 👥 适合谁用 / 不适合谁用
- **适合谁用**：经常需要配置复杂第三方服务、带新人配环境、或者需要频繁在不同机器上初始化项目的团队Leader、全栈开发者和运维人员。
- **不适合谁用**：只做纯前端页面开发、不涉及后端环境变量和第三方密钥配置的人员；或者极度讨厌用命令行（Terminal）、只喜欢图形界面点点点的开发者。

## 📊 综合评分
- **实用性**：8/10（解决了真实的“人工配置”痛点，大幅减少重复劳动，但受限于bash脚本的表现力）
- **易用性**：7/10（对运行者很傻瓜，但生成逻辑较重，且存在一些反人类的输入bug影响体验）
- **创新性**：9/10（巧妙地把“AI无法操作的GUI步骤”转化为了“人机交互的CLI脚本”，思路非常清奇且实用）
- **总分**：8.0/10
