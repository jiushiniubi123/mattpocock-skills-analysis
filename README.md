# Matt Pocock Skills 全面分析与实测

> 37 个技能逐个拆解，非程序员也能看懂的使用指南

## 项目目标

本项目对 [mattpocock/skills](https://github.com/mattpocock/skills) 仓库中的全部 37 个 AI Agent Skill 进行系统性分析和实测验证。每个技能都将经历文档研读、联网调研、场景模拟/实测三个环节，最终输出一份非程序员也能轻松理解的中文使用指南。

通过这个项目，你将了解：
- 每个技能到底是干什么的（大白话解释）
- 什么时候该用它（真实场景举例）
- 它的实际效果如何（真实测评记录）
- 它适合谁、不适合谁（明确的适用边界）

## 测试方法论

每个技能的分析都遵循统一的四步方法论，确保结果客观可比：

1. **文档研读** — 通读 SKILL.md 及所有配套文件，理解设计意图
2. **联网调研** — 搜索社区评价、使用案例、Matt Pocock 相关背景
3. **场景模拟/实测** — 用真实场景实际跑一遍流程
4. **报告输出** — 输出 1500-2000 字的标准化分析报告

详见 [docs/methodology.md](docs/methodology.md)
