# 🗺️ 任务地图：37个 Matt Pocock 技能全面分析

> 本文档是 GitHub Issues 任务地图的本地镜像，用于离线查看和存档。

## 目的地（Destination）

完成全部 37 个技能的详细分析报告和实测验证，让非程序员也能理解每个技能的价值和用法。

## 备注（Notes）

- 每天 1500 积分预算
- 每天凌晨 2 点自动执行
- 优先做非编程 / 高实用性技能
- 按批次推进，每批完成后再开启下一批

## 已完成决策（Decisions so far）

- 采用统一的四步测试方法论（文档研读 → 联网调研 → 场景模拟/实测 → 报告输出）
- 报告模板标准化，每个技能一份 1500-2000 字的中文报告
- 通过 GitHub Issues 管理任务进度，按优先级分 6 批推进

## 待明确（Not yet specified）

- 编程类技能的实测项目选型
- 深度实测的范围边界（测多深、测多久）
- in-progress 技能的测试策略（功能不完整怎么办）

## 超出范围（Out of scope）

- 不进行二次开发
- 不做性能对比基准测试
- 不翻译原始 Skill 代码
